# 客户详情页功能说明

## 功能概述

客户详情页现在包含以下功能：

### 1. 商机记录（Deals）
- 显示客户的所有商机
- 包括：商机标题、金额、预计成交日期、阶段状态
- 商机定义：客户有回复、真实采购时间、采购意愿、采购数量的询价

### 2. 关联线索（Leads）
- 显示与客户关联的线索信息
- 包括：线索标题、联系人、联系邮箱、来源、状态、预计价值
- 线索定义：还没有录入客户之前的潜在陌生客户信息
- 关联方式：线索"转为商机"时会自动创建客户，并将线索与客户绑定（`customer_id`）

### 3. 关联订单（Orders）
- 显示客户的所有订单（含来源商机标题、负责人、状态）
- 订单状态与付款状态直接展示

### 4. 跟进记录（Follow-ups）
- 记录客户的跟进情况
- 类型包括：
  - **比价询价**：客户没有真实采购意愿，只进行比价
  - **无回复**：客户无回复
  - **跟进中**：正在跟进
  - **其他**：其他情况
- 可记录：标题、描述、下一步行动、下次跟进日期
- **完整增删改查（CRUD）都在本页完成**：
  - **增**：表单提交到 `POST /customers/{id}/follow-ups`
  - **查**：列表按创建时间倒序展示，带类型徽章与记录人
  - **改**：每行「编辑」按钮打开弹窗回填原值，`PUT /customers/{id}/follow-ups/{followUpId}`
    （浏览器不直接发 PUT，表单用隐藏字段 `_method=PUT` 伪造）
  - **删**：每行「删除」按钮带确认框，`DELETE /customers/{id}/follow-ups/{followUpId}`
- 改/删前都会校验这条跟进记录确实属于 URL 里的客户，拿别家客户的 ID 改不动也删不掉
- 校验规则与 AI 助手共用一份声明（`FollowUp::$fields`）：标题必填、类型必须是四个取值之一

### 5. 活动记录（Activities）
- 记录电话、会议、备注等一般活动
- 每条活动显示的操作人姓名同样是从 `users` 实时读取（`user_id` JOIN）

### 6. 负责人（实时取之于账号表）
- 客户只存 `owner_id`，姓名在读取时 JOIN `users` 得到，因此**不存在姓名副本**
- 详情页的负责人块除了姓名，还会带出该账号在「设置 → 个人信息」里填的
  **职位、电话、WhatsApp、邮箱**（只展示已填写的项）
- 所以成员改名或换手机号，只需自己在设置里改，本页与列表会立即同步

## 数据库配置

数据库为 SQLite，统一由 `database/schema.sql` + `database/migrate.php` 管理：

```bash
php database/migrate.php
```

## 使用说明

1. **查看客户详情**：点击客户列表中的客户名称
2. **添加跟进记录**：在客户详情页的"跟进记录"区域填写表单并提交
3. **编辑跟进记录**：点该行右侧的铅笔按钮，在弹窗里改完保存
4. **删除跟进记录**：点该行右侧的垃圾桶按钮并确认
5. **添加活动记录**：在"活动记录"区域填写备注并提交
6. **关联商机/订单**：新建商机/订单时选择该客户；线索转商机时自动创建客户并绑定

## 商机 vs 线索 vs 跟进记录

| 类型 | 定义 | 特点 |
|------|------|------|
| 商机 | 有真实采购意向的询价 | 有采购时间、意愿、数量 |
| 线索 | 潜在客户信息 | 尚未转化为客户 |
| 跟进记录 | 比价或无采购意愿的询价 | 记录客户比价情况 |
